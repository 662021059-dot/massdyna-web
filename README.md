# MASSDYNA CORPORATE WEBSITE

เว็บไซต์ตัวอย่างบริษัท Massdyna แบบหลายหน้า รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์

## วิธีเปิดดู
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `massdyna-web`
3. ดับเบิลคลิก `index.html` เพื่อเปิดเว็บไซต์
4. เมนูด้านบนเชื่อมไปยังหน้าต่าง ๆ ภายในชุดไฟล์นี้

## หน้าภายในเว็บไซต์
- `index.html` หน้าแรก
- `solutions.html` โซลูชันทั้งหมด
- `civio.html` เครื่องกำจัดขยะ CiviO
- `conveyor.html` Flexible Conveyor
- `machinery.html` เครื่องจักรอุตสาหกรรม
- `3d-printer.html` เครื่องพิมพ์ 3D
- `services.html` บริการของเรา
- `activities.html` ข่าวสารและกิจกรรม
- `about.html` เกี่ยวกับเรา
- `contact.html` ติดต่อเรา

## ลูกเล่นที่ใส่ไว้
- เมนูติดด้านบนและเมนูมือถือ
- แถบแสดงความคืบหน้าการเลื่อนหน้า
- Smooth scroll / reveal animation เมื่อเลื่อนถึงส่วนต่าง ๆ
- Hero background zoom และ parallax เล็กน้อย
- Hover effect บนการ์ดและปุ่ม
- แถบข้อความเคลื่อนไหว
- ปุ่มโทรศัพท์ อีเมล แผนที่ และลิงก์ไปหน้ารายละเอียด

## เผยแพร่เป็นลิงก์สาธารณะด้วย GitHub Pages
1. เข้าสู่ระบบ GitHub แล้วสร้าง Repository ใหม่ เช่น `massdyna-website`
2. อัปโหลด **ไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ภายใน `massdyna-web`** เข้า Repository (อย่าอัปโหลดเฉพาะ ZIP)
3. ไปที่ Settings → Pages
4. ในส่วน Build and deployment เลือก Deploy from a branch
5. เลือก Branch `main` และ Folder `/ (root)` แล้วกด Save
6. เมื่อ GitHub Pages เผยแพร่เสร็จ จะมี URL สาธารณะรูปแบบ `https://ชื่อผู้ใช้.github.io/massdyna-website/`

## หมายเหตุสำคัญ
- ภาพประกอบบางภาพเรียกจากเว็บไซต์ Massdyna เดิมโดยตรง เพื่อคงภาพผลิตภัณฑ์และกิจกรรมจริง จึงต้องเชื่อมต่ออินเทอร์เน็ตขณะเปิดเว็บไซต์
- ข้อความและข้อมูลติดต่อยึดตามข้อมูลที่ค้นพบจากเว็บไซต์ Massdyna ณ วันที่ 2 พฤศจิกายน 2026 ควรให้บริษัทตรวจทานหมายเลขโทรศัพท์ อีเมล และรายละเอียดผลิตภัณฑ์ก่อนใช้เป็นเว็บไซต์ทางการ
- หน้าติดต่อใช้ลิงก์โทรศัพท์ อีเมล และ Google Maps; ไม่มีระบบรับข้อมูลฟอร์มเข้าฐานข้อมูล
- โครงการนี้เป็น static website ไม่ต้องติดตั้ง PHP หรือฐานข้อมูล
